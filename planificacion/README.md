# Planificación de la historia

Esta carpeta **no se publica** en la web. Es la "biblia" del libro: aquí vive todo lo que
Claude necesita saber para escribir los capítulos de forma coherente.

| Archivo | Para qué sirve |
|---|---|
| `personajes.md` | Fichas de cada personaje |
| `mundo.md` | Lugares, reglas de la magia, historia, cultura |
| `trama.md` | La historia completa, de principio a fin, y sus temas |
| `capitulos.md` | Plan capítulo por capítulo (lo que pasa en cada uno) |
| `estilo.md` | Tono, narrador, tiempo verbal, público, referencias |

Puedes rellenarlos tú directamente o simplemente contarle a Claude la historia en el chat,
y Claude los irá completando.
